# 備品購入依頼

DeltaChatで動くwebxdcアプリ「備品Hub」と、図表入り操作マニュアルをまとめたフォルダーです。備品の依頼登録、重複確認、受付・発注・完了の管理方法を説明しています。

## 同梱ファイル

| ファイル | 用途 |
| --- | --- |
| [Supply_Hub_1.0.0.xdc](Supply_Hub_1.0.0.xdc) | DeltaChat内で開くアプリ本体。パッケージのバージョンは1.0.0です。 |

## 利用を始める

1. DeltaChatで、購入依頼を共有するチャットを開きます。
2. `Supply_Hub_1.0.0.xdc` をファイルとして添付して送信します。
3. チャットに届いたアプリを開きます。参加者は、その同じアプリを開いてください。
4. 一覧を確認し、見本データと実際の依頼の区別を管理担当者と確認します。
5. 少人数で登録と状態変更を試し、別の参加者にも同じ内容が表示されることを確認してから運用を始めます。

詳しい操作はHTML版またはPDF版を参照してください。組織内の運用に合わせて説明を編集する場合はWord版を使います。

## 基本の操作

1. **一覧で検索する**：同じ備品の依頼がないか確認します。古い依頼は年月の条件も確認します。
2. **登録する**：品名、数量、単位、担当者などを入力し、類似依頼を確認して送信します。
3. **購入の対応を進める**：詳細画面で、実際の作業に合わせて受付・発注・完了に変更します。
4. **集計を見る**：レポートで件数などを確認し、必要に応じてCSV出力や要約コピーを使います。

## 対象アプリの注意点

- **登録内容の訂正**：登録後に品名・数量・担当者を編集する画面、削除ボタン、直前の状態に戻すボタンは見当たりません。元の依頼をキャンセルし、正しい内容で新規登録する手順をマニュアルに記載しています。
- **表示金額**：新規依頼の単価は実装上1,000円に固定されています。実際の購入額や精算額として扱わないでください。
- **共有**：「同期中」の表示は相手の受信完了を保証しません。コメントの追加方法や複製にも共有処理の制約が見られます。詳細はマニュアルを参照し、必要な連絡はDeltaChatのチャットでも確認してください。
- **集計**：グラフや出力によって対象期間・絞り込み条件が異なります。CSVや要約を使う前に対象範囲を確認してください。
